# Results Directory

This directory will contain all output files generated by the workflow.

Results are organized into three subdirectories:

## Directory Structure

```
results/
├── plots/       # All visualizations (PDF and PNG)
├── tables/      # CSV files and text summaries
└── objects/     # Saved R objects (.RData)
```

## Generated Content

After running the complete workflow, you will find:

### Plots (`results/plots/`)
- **qc/** - Quality control visualizations
- **normalization/** - Before/after normalization comparisons
- **visualization/** - PCA plots, heatmaps, correlation matrices
- **statistics/** - Volcano plots, MA plots

### Tables (`results/tables/`)
- Summary text files for each workflow step
- Normalized data matrix (CSV)
- PCA results (scores, loadings, variance)
- Statistical analysis results
- List of significant features

### Objects (`results/objects/`)
- `metaboset_raw.RData` - After data import
- `metaboset_filtered.RData` - After quality control
- `metaboset_normalized.RData` - After normalization

## Notes

- This directory is excluded from version control (see `.gitignore`)
- Results are generated fresh each time you run the workflow
- Back up important results before re-running scripts
- All files are created automatically by the workflow scripts
